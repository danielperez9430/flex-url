## Flex Url

<img src="https://raw.githubusercontent.com/open-southeners/partners/main/logos/open_southeners_logo.png" alt="" align="left" height="64">

Zero-dependency URL builder/parser for the apiable request grammar (filters, sorts, includes, fields, appends, pagination, search) — TypeScript and PHP mirror packages.

[![Test](https://github.com/open-southeners/flex-url/actions/workflows/tests.yml/badge.svg?branch=main)](https://github.com/open-southeners/flex-url/actions/workflows/tests.yml) [![codecov](https://codecov.io/gh/open-southeners/flex-url/branch/main/graph/badge.svg)](https://codecov.io/gh/open-southeners/flex-url) [![Edit on VSCode online](https://img.shields.io/badge/vscode-edit%20online-blue?logo=visualstudiocode)](https://vscode.dev/github/open-southeners/flex-url)

## Packages

- [`packages/js`](packages/js) — TypeScript core, published as [`flex-url`](https://npmjs.com/package/flex-url) on npm.
- [`packages/php`](packages/php) — PHP mirror, published as [`open-southeners/flex-url`](https://packagist.org/packages/open-southeners/flex-url) on Packagist.

Method names and wire semantics are kept identical between the two on purpose — see either
package's README for install instructions specific to that language.
