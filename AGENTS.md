# Agent guidance

Follow the [Open Southeners contribution guide](https://github.com/open-southeners/agents/blob/main/skills/opensoutheners-contributor/references/contribution-guide.md).
When available, use the `opensoutheners-contributor` skill.

User instructions and the repository-specific guidance below take precedence
over the shared defaults.

## Repository-specific guidance

See [`CLAUDE.md`](CLAUDE.md) in this repository for flex-url's development
commands, architecture (the functional-core/`FlexUrl`-wrapper/`Encoding`/
`Input` layering, mirrored between `packages/js` and `packages/php`),
cross-language test parity via `fixtures/cases.json`, the encoding contract,
CI/release process, and GitBook documentation conventions for `docs/`.
